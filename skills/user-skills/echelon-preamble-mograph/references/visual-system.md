# Echelon Preamble Visual System

## Format
- 1080 × 1920 px (9:16 vertical)
- 30fps (or match source)
- 20-60 seconds typical duration

## Layer Stack (top → bottom in AE)
1. WM_Echelon — watermark, full duration
2. KW text layers — trimmed to timecodes
3. Cutaway overlays — text on cutaway backgrounds
4. Cutaway video — full-frame, replaces speaker
5. Source_Video — base layer

## ECHELON Watermark
- Text: "ECHELON", all caps
- Font: System default (or Montserrat SemiBold if installed)
- Size: 28px
- Position: [540, 50] — top center
- Color: white, Opacity: 75%
- Animation: fade in 0→75% over 0.5s at start
- Duration: entire comp

## Keyword Typography

### Slam (single big word)
- Font size: 110-140px
- Color: white {r:1, g:1, b:1}
- Position Y: **1740**
- Animation: Scale 115%→100% over 4 frames + Opacity 0→100% over 4 frames
- Exit: Opacity 100%→0% over 4 frames

### Context (small qualifier above slam)
- Font size: 40-55px
- Color: accent color (amber, red, etc.)
- Position Y: **1680**
- Animation: Opacity 0→100% over 3 frames
- Exit: Opacity 100%→0% over 3 frames

### Counter (animated number)
- Number: 100-140px, accent color
- Label: 36-50px, white, below number
- Position: center frame on cutaway background

## Timing Rules
- Keyword appears when speaker BEGINS the word
- Minimum hold: 0.8s
- Gap between keywords: minimum 0.2s
- Density: max 1 keyword per 2-3s
- Maximum: 8-10 keywords per 30s clip

## Animation Specs (at 30fps)

| Animation | Duration | AE Influence |
|-----------|----------|-------------|
| Scale slam in (115→100%) | 4 frames / 0.13s | 75 |
| Opacity fade in | 4 frames / 0.13s | 80 |
| Opacity fade out | 4 frames / 0.13s | linear |
| Source zoom in (100→108%) | 9 frames / 0.3s | 70 |
| Source zoom out (108→100%) | 9 frames / 0.3s | 70 |

## Source Video Zoom
- Apply to ONLY 30% of the clip (2-3 moments max)
- Pick the emotional peaks only
- Scale: 100% → 108% with smooth ease
- Do NOT zoom on every keyword

## Cutaway Screens
- Duration: 3-5 seconds
- Generated by Higgsfield (seedance_2_5, 9:16)
- Prompt must reflect the episode's thematic content
- Text overlays on cutaway: centered, Y range 780-1100
- Cross-fade in/out with speaker segments

## Colors

### Warm Amber/Gold (default for warm-lit studios)
- Accent: {r:0.784, g:0.588, b:0.243} — #C8963E
- Text: white {r:1, g:1, b:1}

### Echelon Red
- Accent: {r:0.89, g:0.10, b:0.22} — #E31937
- Text: white

### Per-episode
- Use the featured brand's color as accent
- Speaker background color is baked in source video

## Rhythm Pattern (30s clip)
```
[0-3s]   Speaker + Keyword 1-2
[3-6s]   Speaker + Keyword 3
[6-9s]   Speaker clean or Keyword 4
[9-12s]  Speaker + Keyword 5
[12-15s] Speaker + Keyword 6 → CUTAWAY
[15-18s] CUTAWAY with concept text
[18-21s] Speaker + Keywords 7-8
[21-24s] End card (if applicable)
```
